# Portafolio-Landing-page
Diseño de portafolio web para el PFO1 de materia Front-End IFTS29.

Portafolio web personal desarrollado como una landing page. Incluye presentación personal con nombre y apellido, resumen de habilidades, canales de contacto y una sección de interés personal a elección.

## Uso de IA

Para el desarrollo de este proyecto se utilizó la inteligencia artificial *Claude* para la generación del código base. Posteriormente, se realizaron las siguientes modificaciones y personalizaciones manuales:

* Actualización y ajuste de los enlaces externos utilizados en la página.
* Reemplazo y optimización de las imágenes del sitio.
* Adaptación de la paleta de colores a la identidad visual deseada.
* Rediseño y ajuste tipográfico del título según las preferencias personales.
